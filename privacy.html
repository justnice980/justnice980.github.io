Privacy Policy

Last updated: September 15, 2026

This OAuth application is for private, non-commercial use by its owner with rclone on a personal Linux computer.

Google user data accessed

The application requests read-only Google Drive access so rclone can list file and folder metadata and download file contents selected by the account owner.

Use of data

Google Drive data is used only to copy files requested by the account owner to the owner's local storage. The application does not upload, edit, move, rename, or delete Google Drive content.

Storage and sharing

Downloaded files and OAuth credentials remain on the owner's personal computer. Google user data is not sold, shared with third parties, used for advertising, or used to train models.

Retention and deletion

The owner controls downloaded files and may delete them locally at any time. OAuth access can be revoked from the Google Account permissions page.
